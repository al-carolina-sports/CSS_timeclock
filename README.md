# CSS Timeclock

Private WordPress timeclock work for Carolina Sports and Spine / BioFunctional / True Radiance.

## Layout

- `css-timeclock-addon/` — WordPress plugin (PIN + name-list kiosks and a public who’s-working board on AIO Time Clock Lite)
- `docs/CSS-Timeclock-Whitepaper.md` — developer whitepaper
- `dist/css-timeclock-addon.zip` — WP Engine upload zip

## Install (sandbox only)

Upload `dist/css-timeclock-addon.zip` via **Plugins → Add New → Upload** on `carolinaspodev` only. Keep AIO Time Clock Lite active.

Do not install on live marketing sites without explicit approval.
